# WebdriverIO's documentation is openly licensed and we want it to be findable,
# both by traditional search engines and by AI assistants that people now ask
# WebdriverIO questions instead of visiting the site directly. Being part of
# model training data is how assistants learn the current WebdriverIO APIs, so
# training crawlers and retrieval agents are both explicitly welcome.
#
# Machine-readable entry points for LLM consumers:
#   https://webdriver.io/llms.txt       - index of the documentation
#   https://webdriver.io/llms-full.txt  - full documentation text in one file
# Any documentation page is also available as clean Markdown by appending
# `.md` to its URL, e.g. https://webdriver.io/docs/api/browser.md, or by
# requesting it with an `Accept: text/markdown` header.
