# `.md` to its URL, e.g. https://webdriver.io/docs/api/browser.md
#
# NOTE: no per-crawler stanzas are declared yet. Whether to allow or disallow
# specific AI training crawlers (GPTBot, ClaudeBot, CCBot, Google-Extended,
# Applebot-Extended, ...) separately from retrieval/citation agents
# (OAI-SearchBot, ChatGPT-User, Claude-User, PerplexityBot, ...) is a project
# policy decision, not a technical one. Until that is settled the site stays
# open to everything, which matches the behaviour before this file existed.
